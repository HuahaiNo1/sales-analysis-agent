## 路径与结果

在同一服务生命周期中启动本地 PostgreSQL 与真实 FastAPI HTTP 服务，用演示账号通过登录/会话/运行 API 发起一个明确的 2025 年按月销售额问题。

- 真实 DeepAgents 主 Agent 调用 4 次，唯一 analysis 子 Agent 调用 2 次，6 次均成功返回合法 usage
- 工具过程：读取指标目录 → query_metrics → DeepAgents 原生 task 分发 analysis → analyze_result
- 17.42 秒完成，本次运行状态 succeeded
- 查询语义正确：sales_amount、2025-01-01 至 2026-01-01（结束日不含）、按月分组
- 12 个月结果逐项匹配独立只读 PostgreSQL 汇总 SQL
- 2025 年总销售额精确值：112377303.726292 USD，匹配独立 SQL
- 授权 CSV 下载成功，12 行聚合数据；没有导出客户个人明细
- 另一演示账号读取该会话、运行、结果、CSV 均返回 404，跨账号访问被拒绝

模型只接触本项目公开合成数据的指标定义和受控汇总结果。验收记录不含密钥、请求头、完整模型提示或供应商原始响应。

## 一处必要修复

首次 live 客户端构建发现环境原有 SOCKS 代理所需的 HTTPX 可选依赖缺失，在发请求前失败，费用记录为零。已将依赖改为官方 `httpx[socks]` 并锁定 socksio 1.0.0；没有更换代理或放宽安全设置。随后真实构建与上述 API 验收通过。

## 边界与恢复

仅一个真实业务场景已通过，不能据此声称所有自然语言/比较/贡献问法均通过真实模型验收。浏览器登录点击、实际图表渲染和移动布局仍未验证。API 与数据库测试结束后已停止；没有推送 GitHub 或部署。

私有运行账本保留在原位置，不随源码 ZIP 分发。若迁移环境并继续同一次 5 元开发预算，必须人工带入当前已占用金额或受控迁移现有账本，再启用真实调用；不能将新机器新建的空账本当成原预算仍被保留，更不能用重建账本重置额度。
