# Contoso Insight 前端

Vue 3 + TypeScript + Vite 的中文销售分析工作台。图表使用 Apache ECharts，图标使用 Lucide。浏览器不保存模型密钥，也不进行权限决策。

## 启动

建议从项目根目录运行统一启动脚本，以保证 PostgreSQL、FastAPI 和 Vite 位于同一执行环境：

```bash
cd /workspace/shared/sales-analysis-agent
scripts/dev.sh
```

普通开发环境也可以分别启动后端与前端：

```bash
cd frontend
npm ci
npm run dev
```

前端默认监听 `127.0.0.1:5173`，通过同源 `/api` 代理访问 `127.0.0.1:8000`。本地回环地址不等于可从外部访问的部署网址；目前没有发布、推送或部署。

演示登录：`admin / demo123` 和 `analyst / demo123`。前者是全门店演示账号，后者仅有三家门店权限；实际权限由后端会话和数据查询共同校验。

## 页面与交互

- 销售概览：五个指标卡、自然年快捷切换、包含结束日期的日期筛选和月度趋势
- 销售助手：问题输入、示例问题、连续追问、运行状态、停止、澄清、拒绝、错误与无数据反馈
- 查询结果：表格、折线、柱状与贡献瀑布图；图表切换复用同一结果，不再次调用模型；聊天中的纯展示追问也恢复服务端保存的 presentation，保持原结果不变
- 结果详情：期间、数据版本、来源、结果 ID、授权范围和口径说明
- CSV：只对服务端保存的会话结果开放；请求时使用当前 HttpOnly 会话 Cookie 再次授权
- 分析记录：本浏览器保存最近会话索引，消息、查询上下文和结果均恢复自后端
- 指标口径和数据权限：完整展示五指标定义、权限范围、模拟数据说明和模型/预算模式
- 响应式：桌面双列工作台，小屏改为单列，并使用可收起导航

“新建会话”清空的是业务上下文，不修改权限、不删除历史。退出登录或切换演示身份后，不复用另一个身份的前端结果。

## 数据和费用说明

所有展示值来自后端 API，页面没有生产数据回退夹具。登录页的小柱形图仅为装饰，已明确标注，不是查询统计。Contoso 是合成数据，不能外推真实市场规律或因果关系。

顶部始终显示 `MOCK` 或 `LIVE`。MOCK 是本地确定性模型，仍由后端 Deep Agents 流程执行受控工具，不产生外部模型费用。LIVE 的模型调用、预留预算和上限由后端控制；页面以人民币分别显示已结算用量估算、未决预留、合计预算占用和剩余额度；占用不是实际账单费用。前端 `.env` 不需要任何模型密钥。

金额及数量的权威精确值是后端十进制结果。图表绘制使用 JavaScript 数值，界面按 USD/计数格式展示；CSV 直接下载后端文件，不从图表像素或格式化标签重算。

## 检查命令

```bash
npm run typecheck
npm run build
npm test
```

浏览器端到端检查需要真实后端和 PostgreSQL，测试不拦截 API、不填入伪造业务响应：

```bash
# 从项目根目录运行
scripts/dev.sh --test-e2e
```

测试默认使用 `/usr/bin/chromium`，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定测试环境已有的 Chromium。覆盖登录、KPI/API 一致性、日期校验、月度查询、图表/表格、CSV、多轮追问、刷新恢复、贡献瀑布、拒绝/澄清、重置与历史、两个账号的跨结果访问拒绝和移动端布局。

截图、失败 trace 和 JSON 测试结果位于 `frontend/test-results/`，这些文件不纳入版本控制。最终通过与未运行项以项目验收记录为准。

## 安全边界

- 使用后端 HttpOnly Cookie；本地存储只有按用户名隔离的会话索引，不保存密码或访问令牌
- 所有模型输出以 Vue 文本插值显示，不执行模型 HTML、脚本或任意 ECharts 配置
- 图表只由本地受控函数根据结果列构造，提示框为 rich-text 而非 HTML
- 前端按钮可见性不是授权；后端在结果读取、查询和 CSV 导出时强制校验身份
- 无匹配数据、运行失败和取消是不同状态，不会用上次结果冒充本次成功
- 原始日期控件为包含结束日；发送到 API 时转为左闭右开区间
- 运行中的请求锁住重复提交；版本冲突会重新读取服务端版本，不偷偷覆盖查询
- 请求中断后继续获取服务端运行状态；刷新可以恢复尚未完成的运行

## 主要文件

- `src/App.vue`：登录、应用布局、会话与异步状态协调
- `src/lib/api.ts`：同源 API、错误处理和授权 CSV
- `src/lib/charts.ts`：受控图表和瀑布计算
- `src/lib/format.ts`：指标字典、日期与数值显示
- `src/components/QueryResult.vue`：结果图表、明细和来源说明
- `src/components/ChartView.vue`：按需加载 ECharts、ResizeObserver 和销毁清理
- `tests/`：纯函数测试；其中小样本仅用于测试，未引入应用运行路径
- `e2e/`：真实服务浏览器测试
